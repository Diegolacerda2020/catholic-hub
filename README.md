# Branch de dados (automático)

`noticias.json`: espelho das notícias da Arquidiocese de BH, atualizado de hora em hora pelo
workflow `.github/workflows/noticias.yml` do branch `main`. Não edite à mão.
Guarda só título, data, rótulo, resumo curto, imagem e link de cada notícia (nunca a matéria completa).
